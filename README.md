# Spot – Nimbl'Bot

Ce dépôt regroupe les principaux développements réalisés durant mon stage chez **Nimbl'Bot** autour de l'utilisation du robot quadrupède **Spot** avec le bras manipulateur de l'entreprise.

## Environnement

Principaux outils utilisés :

- Python
- ROS 2 Humble
- Placo
- Spot SDK
- MeshCat
