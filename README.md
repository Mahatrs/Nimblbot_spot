# Spot – Nimbl'Bot

Ce dépôt regroupe les principaux développements réalisés durant mon stage chez **Nimbl'Bot** autour de l'utilisation du robot quadrupède **Spot** avec le bras manipulateur de l'entreprise.

## Contenu

Le dépôt contient principalement :

- quelques **scripts Python** utilisés pour la simulation, la cinématique inverse, le positionnement et les différents tests réalisés ;
- `ros_ws_humble` : workspace ROS 2 utilisé pour la commande et les développements liés au bras **Nimbl'Bot** et les launch files;
- le **workspace ROS 2 de Spot**, utilisé pour la communication et la commande du robot quadrupède.


## Environnement

Principaux outils utilisés :

- Python
- ROS 2 Humble
- Placo
- Spot SDK
- MeshCat
